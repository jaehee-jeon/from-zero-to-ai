## 📌 문제 1. [1주차] NumPy·Pandas
해설 담당: 전재희

```python
고객 100명의 구매 금액 데이터가 리스트로 있습니다: [12000, 15000, 8000, 22000, 9000, ...]. 이 데이터의 평균 구매 금액을 계산하려고 합니다. Python 기본 함수 대신 NumPy를 사용하면 더 빠르고 간단하게 계산할 수 있습니다.
```

**NumPy 라이브러리를 import하고, 위 리스트의 평균을 구하는 코드 1줄을 작성하세요. (변수명은 purchases라고 가정)**

💡 힌트: numpy를 np로 import하고, np.mean() 함수를 사용하세요

🌍 실무에서는 이렇게 써요:
실무에서 Azure ML로 AI 모델을 학습시킬 때, 수천~수만 개의 데이터를 다룹니다. NumPy는 이런 대용량 숫자 데이터를 빠르게 계산하는 기본 도구이고, Pandas는 엑셀처럼 표 형태 데이터(고객정보, 거래내역 등)를 쉽게 정리·분석하는 도구입니다. Azure OpenAI에 보낼 데이터를 전처리할 때도 필수적으로 사용됩니다.
