## 0. Python이란? 그리고 왜 쓰는가?

Python은 **범용 프로그래밍 언어**다.  
2025년 기준 TIOBE 인덱스 1위. 전 세계 개발자의 80% 이상이 데이터 작업에 Python을 사용한다.

Python 하나로 할 수 있는 것들이 많지만, 우리 수업은 **데이터 분석** 파트다.

```
Python (언어 전체)
├── 웹 개발
├── 자동화
├── AI / 머신러닝
└── 데이터 분석  ← 우리가 하는 것

    ├── 처리·정제 (Pandas, NumPy)
```

> **핵심**: 시각화는 데이터 분석의 마지막 단계가 아니다.

## 1. 왜 시각화가 필요한가?

### 숫자만으로는 설득이 안 된다

**표로 볼 때 — 뭔가 이상한데, 언제부터지?**

| 월 | 판매량 |
|---|---|
| 1월 | 1,200 |
| 2월 | 1,180 |
| 3월 | 980 |
| 4월 | 610 |

**그래프로 볼 때 — 0.3초 만에 보인다: 4월에 급감했다.**

이 차이가 조직 안에서 **의사결정 속도**를 바꾼다.  
데이터를 분석하는 사람만 이해하는 것이 아니라, **모든 레벨의 구성원이 같은 그림을 보고 빠르게 판단**할 수 있어야 한다. 그게 시각화의 진짜 역할이다.

---

### 데이터 작업 흐름에서 시각화는 어디에 있나?

```
1. 원시 데이터 수집
         ↓
2. 데이터 정제 (Pandas)     ← 이상한 값 있는지 그래프로 먼저 확인
         ↓
3. 탐색적 분석 EDA           ← 시각화가 핵심 도구 (Seaborn 주로 사용)
         ↓                     * EDA = 모델 만들기 전에 데이터를 눈으로 먼저 훑어보는 과정
4. 모델 학습 (Azure ML)
         ↓
5. 모델 성능 평가             ← ROC 커브, 혼동행렬을 그래프로 확인 (Matplotlib)
         ↓
6. 결과 보고·공유             ← 대상에 따라 도구가 달라짐
```

---

### 누구에게 보여주느냐에 따라 도구가 달라진다

| 대상 | 필요한 것 | 적합한 도구 |
|---|---|---|
| 나 / 데이터팀 | 빠른 탐색, 코드와 함께 | Matplotlib, Seaborn |
| 팀 내부 공유 | 클릭·필터 가능한 인터랙티브 | Plotly |
| 경영진 보고 | 코드 없이 클릭만으로 조작 | Power BI (Azure ML 연동) |
| 위치 데이터 | 지도 위에 표현 | Folium |

## 2. Matplotlib — Python 시각화의 뿌리

**한 줄 요약**: 모든 Python 시각화의 출발점. Seaborn, Plotly 등 다른 라이브러리들도 내부적으로 Matplotlib을 사용한다.

```python
pip install matplotlib
import matplotlib.pyplot as plt
```

> **왜 `matplotlib.pyplot`이라고 쓰나?**  
> `matplotlib` 자체는 거대한 패키지다. 그 안에서 그래프 그리는 기능만 모아둔 것이 `pyplot` 모듈이다.  
> `pyplot`만 골라서 불러오기 때문에 `matplotlib.pyplot as plt`라고 쓴다.

**언제 쓰나**: 그래프를 세밀하게 조정해야 할 때, 논문·보고서용 정적 이미지, 특정 지점 강조

---

### 예시 1: Seaborn과 같은 데이터로 비교 — 막대그래프

```python
import matplotlib.pyplot as plt

months = ['Jan', 'Feb', 'Mar', 'Apr']
sales  = [1200, 1180, 980, 610]

plt.figure(figsize=(6, 4))             # 캔버스 크기 — 직접 설정
plt.bar(months, sales, color='steelblue')  # 색상 — 직접 지정
plt.title('Monthly Sales')
plt.ylabel('Sales')
plt.ylim(0, 1400)                      # y축 범위 — 직접 설정
plt.show()
```

→ 색상, 축 범위, 크기 — 하나하나 내가 직접 써야 한다. 이것이 **저수준(low-level) API**의 의미다.  
저수준 = 도구가 대신 정해주는 게 없다. 내가 말한 것만 그린다.

![Matplotlib 막대그래프 — 직접 설정한 색상·범위 표시](01_matplotlib_bar.png)

---

### 예시 2: Matplotlib이 적합한 상황 — 모델 학습 곡선

```python
import matplotlib.pyplot as plt

epochs    = list(range(1, 11))
train_acc = [0.60, 0.70, 0.78, 0.83, 0.87, 0.90, 0.92, 0.93, 0.94, 0.95]
val_acc   = [0.58, 0.67, 0.74, 0.79, 0.81, 0.82, 0.81, 0.80, 0.79, 0.78]

plt.plot(epochs, train_acc, label='Train Accuracy', color='steelblue')
plt.plot(epochs, val_acc,   label='Val Accuracy',   color='orange', linestyle='--')
plt.axvline(x=7, color='red', linestyle=':', label='Overfitting starts')  # 특정 지점 강조
plt.title('Model Training Curve')
plt.xlabel('Epoch')
plt.ylabel('Accuracy')
plt.legend()
plt.show()
```

→ **왜 Matplotlib인가**: "에포크 7부터 과적합 시작"처럼 **특정 지점을 정밀하게 강조**해야 할 때.  
`plt.axvline()` 같은 세밀한 제어는 Seaborn으로 하기 어렵다.

![Matplotlib 모델 학습 곡선 — 과적합 시작점 강조](03_matplotlib_curve.png)

## 3. Seaborn — 통계 탐색 전용

**한 줄 요약**: Matplotlib 위에 만들어진 도구. 짧은 코드로 통계적으로 의미 있는 그래프를 자동 생성한다.

```python
pip install seaborn
import seaborn as sns
import pandas as pd   # Seaborn은 Pandas 데이터프레임을 입력으로 받는다
```

**언제 쓰나**: 분석 초반 EDA, 변수 간 관계 파악, 분포 확인

---

### 예시 1: Matplotlib과 같은 데이터로 비교 — 막대그래프

```python
import seaborn as sns
import pandas as pd

df = pd.DataFrame({
    'month': ['Jan', 'Feb', 'Mar', 'Apr'],
    'sales': [1200, 1180, 980, 610]
})

sns.barplot(data=df, x='month', y='sales')
# 색상·테두리·오차범위(95% 신뢰구간) 자동 적용
```

→ 같은 결과인데 코드가 절반이다. 색상·스타일을 내가 지정하지 않아도 자동으로 나온다.  
이것이 **고수준(high-level) API**의 의미다. 도구가 나머지를 알아서 채워준다.

![Seaborn 막대그래프 — 같은 데이터, 자동 스타일 적용](02_seaborn_bar.png)

---

### 예시 2: Seaborn이 적합한 상황 — 상관관계 히트맵

```python
import seaborn as sns
import pandas as pd

df = pd.DataFrame({
    'Temp':  [15, 20, 25, 30, 35],
    'Humid': [40, 45, 60, 70, 80],
    'Sales': [200, 350, 500, 480, 310]
})

sns.heatmap(df.corr(), annot=True, cmap='coolwarm', vmin=-1, vmax=1)
# df.corr()    : 변수 간 상관계수 자동 계산 (-1 ~ 1)
# annot=True   : 숫자를 셀 안에 직접 표시
# cmap         : 색상 자동 매핑 (파랑=음의 관계, 빨강=양의 관계)
```

→ **왜 Seaborn인가**: 두 줄로 "온도·습도·판매량이 서로 얼마나 관련 있는가"를 즉시 파악 가능.  
Matplotlib으로 같은 결과를 내려면 20줄 이상 필요하다.

![Seaborn 상관관계 히트맵](04_seaborn_heatmap.png)

## [개념 차이] Matplotlib vs Seaborn

| | Matplotlib | Seaborn |
|---|---|---|
| API 수준 | 저수준 — 모든 것 직접 설정 | 고수준 — 자동 스타일 적용 |
| 코드량 | 많다 (7~10줄) | 적다 (3~4줄) |
| 데이터 입력 방식 | 리스트, 배열 직접 | Pandas 데이터프레임 |
| 통계 기능 | 없음 (직접 계산해야) | 오차범위·회귀선 자동 |
| 커스터마이징 | 매우 자유롭고 세밀함 | 제한적 (필요시 Matplotlib 혼용) |
| 주 사용 시점 | 최종 보고, 세밀한 조정 | 탐색 단계 EDA |

**선택 기준**: 빠르게 탐색 → Seaborn. 정밀하게 보여줘야 → Matplotlib.

## 4. Plotly — 인터랙티브 그래프

**한 줄 요약**: 마우스로 조작하는 그래프. 클릭·줌·필터가 되는 HTML을 코드 몇 줄로 만든다.  
Matplotlib·Seaborn이 사진이라면, Plotly는 살아있는 웹 그래프다.

```python
pip install plotly
import plotly.express as px
```

**언제 쓰나**: 팀 내부 공유, 웹 배포, 청중이 직접 데이터를 탐색하게 하고 싶을 때

> 📖 더 알아보기: [Plotly란? — 위키독스](https://wikidocs.net/185024)

---

### 예시 1: Matplotlib과 같은 데이터로 비교 — 막대그래프

```python
import plotly.express as px
import pandas as pd

df = pd.DataFrame({
    'month': ['Jan', 'Feb', 'Mar', 'Apr'],
    'sales': [1200, 1180, 980, 610]
})

fig = px.bar(df, x='month', y='sales', title='Monthly Sales', text='sales')
fig.show()
# HTML로 출력됨 → 마우스 올리면 수치 팝업, 드래그로 줌, 범례 클릭으로 토글
```

→ 코드량은 Seaborn과 비슷하지만, 결과물이 **인터랙티브 HTML**이다.  
아래 이미지는 정적 캡처본 — 실제 실행 시 마우스를 올리면 정확한 수치가 팝업으로 뜬다.

![Plotly 막대그래프 — 실제 실행 시 인터랙티브](05_plotly_bar.png)

---

### 예시 2: Plotly가 적합한 상황 — 지점별 방문객 vs 매출 버블차트

```python
import plotly.express as px
import pandas as pd

df = pd.DataFrame({
    'Branch':   ['Gangnam', 'Hongdae', 'Jamsil', 'Sinchon', 'Itaewon'],
    'Sales':    [4500, 2100, 3200, 1800, 2700],   # 단위: 만원
    'Visitors': [1200, 890, 1100, 650, 970],
    'District': ['Gangnam-gu', 'Mapo-gu', 'Songpa-gu', 'Seodaemun-gu', 'Yongsan-gu']
})

fig = px.scatter(df,
    x='Visitors', y='Sales',
    size='Sales',      # 버블 크기 = 매출
    color='District',  # 색상 = 지역 구분
    text='Branch',     # 각 점에 지점명 표시
    title='Branch: Visitors vs Sales'
)
fig.show()
```

→ **왜 Plotly인가**: "강남이 방문객은 많은데 왜 매출은 잠실보다 낮지?"  
이런 질문을 그래프를 직접 클릭·줌하면서 탐색할 수 있다.  
Matplotlib이라면 "코드 수정 → 재실행"을 반복해야 한다.

![Plotly 버블차트 — 실제 실행 시 각 버블 클릭·줌 가능](06_plotly_bubble.png)

## 5. Folium — 지도 위의 데이터

**한 줄 요약**: 지리적 데이터를 지도 위에 표현하는 도구. HTML 파일을 출력한다 — 이미지가 아니다.

```python
pip install folium
import folium
```

**언제 쓰나**: 지역별 매출, 물류 경로, 사용자 분포 등 위치 정보가 있는 데이터

> 📖 더 알아보기: [Folium: 지도 시각화 라이브러리 — 위키독스](https://wikidocs.net/234454)

---

### 예시 1: 기본 지도 — Jupyter에서 바로 보기

```python
import folium

m = folium.Map(location=[37.5665, 126.9780], zoom_start=12)  # 서울 시청 기준
m   # ← 이 줄이 있어야 Jupyter에서 인라인으로 보임
```

---

### 예시 2: 마커 추가 — 매장 위치 표시

```python
import folium

m = folium.Map(location=[37.5665, 126.9780], zoom_start=12)

stores = [
    {'name': '강남점', 'lat': 37.4979, 'lng': 127.0276, 'sales': '월 3,200만'},
    {'name': '홍대점', 'lat': 37.5563, 'lng': 126.9236, 'sales': '월 2,100만'},
    {'name': '잠실점', 'lat': 37.5133, 'lng': 127.1028, 'sales': '월 4,500만'},
]

for store in stores:
    folium.Marker(
        location=[store['lat'], store['lng']],
        popup=f"{store['name']}: {store['sales']}",  # 클릭하면 팝업 표시
        tooltip=store['name']                         # 마우스 올리면 이름 표시
    ).add_to(m)

m
```

→ **왜 Folium인가**: "강남·홍대·잠실 중 어디가 매출이 높은가"를  
표로 보면 위치 관계가 안 보인다. 지도 위에서는 0.3초 만에 파악된다.

## [실수 포인트] Folium — 지도가 안 보이는 이유

### 문제가 된 코드

```python
folium.Map(location=[37.5, 127.0]).save('map.html')
# ❌ 파일 저장만 됨 → Jupyter 화면에 아무것도 안 나타남
```

### 왜 헷갈렸나?

`plt.show()`는 실행하면 이미지가 바로 화면에 나타난다.  
그래서 Folium도 같을 거라고 기대한 것 — 완전히 합리적인 오해다.

### 핵심 차이

| | Matplotlib / Seaborn | Plotly | Folium |
|---|---|---|---|
| 출력 방식 | 이미지(PNG) 생성 | HTML 객체로 Jupyter에 직접 전달 | HTML 파일로 디스크에 저장 |
| Jupyter에서 바로 보이나? | ✅ | ✅ | ❌ (변수 호출 필요) |
| 인터랙티브 | ❌ | ✅ | ✅ (지도 조작 가능) |

### 올바른 방법

```python
# ✅ 방법 1 — Jupyter에서 인라인으로 보기
m = folium.Map(location=[37.5, 127.0], zoom_start=12)
m   # 마지막 줄에 변수명만 입력

# ✅ 방법 2 — 파일로 저장 후 브라우저에서 열기
m.save('map.html')
```

> **기억할 것**: `.save()`는 저장이지 출력이 아니다.  
> Jupyter에서 보려면 반드시 **변수에 담고 → 마지막 줄에 변수명 호출**.

## [응용] Azure ML 실무 — 누구에게 어떤 도구를?

### 데이터 과학팀 내부 → Matplotlib + Seaborn

Jupyter Notebook 안에서 코드와 그래프가 함께 보인다.  
분석 과정을 문서화하면서 동시에 시각화 가능.  
ROC 커브, 혼동행렬, 특성 중요도 그래프에 주로 사용.

### 팀 내부 공유 → Plotly

코드 몇 줄로 인터랙티브 HTML 생성.  
링크로 공유하면 누구나 클릭·필터·줌 가능.  
경영진 발표 전 팀 내 검토 단계에 적합.

### 경영진 대시보드 → Power BI (Azure ML 직접 연동)

Azure ML 모델 결과를 코드 없이 대시보드에 바로 반영.  
클릭만으로 필터링·드릴다운 가능.  
Microsoft 생태계 표준 — Azure와 네이티브 연동.

> Plotly/Dash는 Python 개발팀이 직접 웹앱을 만들 때의 선택지다.  
> 경영진이 직접 사용하는 도구는 Power BI다.

### 실무 흐름

```
Seaborn / Matplotlib → 분석·탐색
           ↓
        결론 도출
           ↓
  Plotly → 팀 내부 검토용 인터랙티브 리포트
           ↓
  Power BI → 경영진 대시보드 (Azure ML 연동)
```

## 정리 — 라이브러리 한눈에 비교

| 라이브러리 | 한 줄 정의 | 출력 형식 | 주 사용 시점 |
|---|---|---|---|
| Matplotlib | Python 시각화의 뿌리 | 이미지 (PNG) | 세밀한 조정, 최종 보고 |
